# DEMO BRAND · OZON 视觉设计系统 v1

> 依据：ozon.ru 真实抓取的 20 个头部商品（5 个类目，评分 4.7–4.9，评价 4k–47k），见 `raw/ozon-visual/`。
> 目标：**同一套系统，按产品风格换皮** —— 系列统一、单品有性格、信息可复用。

## 1. 画布与网格

- 画布：**1500×2000（3:4）**，sRGB，JPEG 质量 90（Ozon 图集容器是 3:4，方图会留白）
- 安全边：左右 80px，顶部 90px，底部 120px
- 版式：品牌条（左上）+ 徽章（右上）→ 标题区（y 300–600）→ 卖点卡（右侧 942–1412）→ 产品（主体下半）→ 参数条（底部 3 个白底胶囊）
- 文字覆盖率 ≤25%；每张图只讲 1 个主张

## 2. 字体与字阶

| 用途 | 字体 | 字号 | 用法 |
|---|---|---|---|
| 大标题 | Oswald Bold（西里尔已验） | 118–140px | 全大写，2 行，第一行品牌色、第二行白 |
| 数字/参数 | Oswald Bold | 100–160px | −40 °C、6 метров、1,5 л |
| 卖点标题 | Oswald SemiBold | 48–56px | 3–5 个词 |
| 说明 | Montserrat Medium | 24–33px | 一行，不加句号 |
| 徽章 | Oswald Bold | 46–60px | 2в1 / 5,5 M / LED |

## 3. 标注件与图标

- 卖点卡：深色半透明圆角矩形（#0C162C / 214 alpha），左侧 7px 品牌色竖条，细线图标 28–34px
- 徽章：右上角圆角标签，品牌色底 + 深色字；宽度按文字自适应
- 参数胶囊：白底 236 alpha，深色大字 + 灰色小字
- 图标库（统一线宽 4）：bristle 毛刷 / thermo 温度 / ruler 尺寸 / layers 分层 / paw 爪 / shield 安全 / drop 防水 / led 灯 / box 包装
- 图形语言：双向箭头标尺寸、剖面图标结构、1-2-3 编号标步骤、圈选放大标微距

## 5. 每个 SKU 的 8 张图结构（对齐头部卖家 + 我们的创新）

| # | 类型 | 头部通行做法 | 本系统创新点 |
|---|---|---|---|
| 1 | Hero 海报 | 场景 + 大字 + 3 卖点 | 同左，但参数用**实称值**（487 г / 68–91 см） |
| 2 | 核心卖点 + 大数字 | 单图标 + 数字 | 数字全部来自实测/证书，不编 |
| 3 | 结构/剖面 | 剖面图、分层 | 加"为什么重要"一行事实解释 |
| 4 | 尺寸参数 | 箭头 + cm/mm | 加卷尺/卡尺实拍，尺寸可核对 |
| 5 | **实测/对比（创新）** | 竞品多只给结论 | 我们做**测试图**：划痕测试、蜡烛透风测试、碎屑测试、0 °C 粘贴测试、LED 血管测试 |
| 6 | 使用/安装步骤 | 1-2-3 照片条 | 步骤保持 3 步，每步一句指令 |
| 7 | 包装清单/兼容性 | 平铺清单 | 数量与长度写实（5,5 м 实测、内含物逐件） |
| 8 | 白底产品图 + 视频位 | 白底图靠后 | 白底图作为合规兜底；视频 15–30 秒实拍+测试 |

## 6. 合规与红线

- 主图不写价格/折扣/«хит продаж»/库存数；不承诺"100% 不坏"
- 不冒用认证（РУ №、MADE IN EU）除非真的有；我们只用"проверено"（实测）话术
- 俄文只用西里尔+数字，字体必须含西里尔（Oswald/Montserrat 已验证）
- 文字高度 ≤ 画面 1/5；单图文字 ≤25%
- 白底图保留 1 张，便于后续换实拍

## 7. 生产流水线（低成本、可复用）

1. **Lovart 出背景板**：每 SKU 2–3 张无产品场景（3:4，约 14 credits/张）
2. **产品抠图**：现有 2048 白底图 → 透明 PNG（Pillow 阈值 + erode，白色产品改用照片卡）
3. **本地合成**：`scripts/design-system-heroes.py` 的参数化模板（theme dict：色板/标题/卖点/参数/产品位置）
4. **QA**：尺寸 1500×2000、文字 ≤25%、西里尔无乱码、参数与实测一致
5. 量产：5 SKU × 8 张 ≈ 生成成本 300–400 credits，其余全本地

## 9. 五种产品原型（archetype）——同品牌，不同设计语言

> 原则：**风格由产品决定，不由模板决定**。每套图先定"谁是主、谁是次、背景在说什么"，再排版。

| SKU | 原型 | 主（第一眼） | 次 | 背景的作用 | 字体/图形 |
|---|---|---|---|---|---|
| W2 扫雪刷 | 动作/性能 | 产品 + 场景动作 | 参数条 | 雪夜街道=使用场景与紧迫感 | Oswald 粗黑、黄黑对比、斜向构图 |
| P1 猫抓板 | 生活方式/编辑 | 猫在抓板上的真实照片 | 标题 + 3 个软胶囊 | 客厅暖光=家的安全感 | Montserrat、奶油底、圆角、无硬边 |
| H1 门缝条 | 技术/蓝图 | 剖面图 + 9×6 数字 | 实拍小图 + 参数 | 石墨网格=工程可信 | 细线、红色标注、等宽感数字 |
| W4 热水袋 | 护理/杂志 | 产品（瓶+毛绒套） | 圆形容量徽章 | 虚化居家=放松、被照顾 | 细字重、玫瑰/奶油、大量留白 |
| B1 指甲剪 | 临床/极简 | 白底产品大图 | 细线卖点行 | 近白背景=医疗器械的洁净 | 细线、蓝、留白、无重色块 |

**主次规则（每张图只允许一个"主"）：**
1. 主元素占画面 35–50%，且对比度最高
2. 次元素（文字/参数）不得超过主的视觉重量；文字覆盖 ≤25%
3. 背景只能做三件事之一：说明场景、提供质感、衬托主体；不能抢主体
4. 产品与背景的关系必须能被一句话说清（"猫在用"/"装在门上"/"握在手里"）

## 10. P1 主次修正（反馈落地）

- 旧版：产品抠图巨大 + 背景里还有一只猫 = 两个主体，视线打架
- 新版：**整张生活方式照为主**（猫正在抓板），标题与三个胶囊为次，产品在真实使用关系里出现
- 同逻辑应用到 P1 其余 7 张：照片为主、文字为次、去掉了深色海报底

## 11. 主图规则（2026-11-10 确定，覆盖此前"白底首图"做法）

**主图 = 带文字描述的 Hero 海报（`01_hero`），不是白底产品图、也不是纯场景图。**

- 主图必须一眼读出：品牌条 + 右上徽章 + 俄文大标题（产品是什么）+ 1–2 个卖点 + 参数胶囊；图里参数必须与 listing facts 一致。
- 白底图（`00_main`）不再是首图：需要合规留档就放图集最后一张，或单独走白底位，不要占第 1 位。
- 图集固定顺序：`01_hero → 02_feature → 03_structure → 04_size → 05_test → 06_steps → 07_kit`（共 7 张；白底可选第 8 张放最后）。
- 上架实现：`POST /v2/product/pictures/import`，`images[0] = 01_hero`，`primary_image = 01_hero`。
- 校验：`/v2/product/pictures/info` 的 `primary_photo` 必须指向 01_hero 的 Ozon CDN 地址；下载主图抽查，右下角编号应为 `DEMO BRAND · 01/08`。
- Ozon 图片处理是异步的：重传后旧主图会顶一阵（实测 2–8 分钟），以 `primary_photo` 轮询结果为准，不要以提交结果为准。
- 风险：Ozon 官方要求主图白底无文字；实测 5 个 SKU 的带字海报主图已被接受。若某天被审核驳回，退路是"白底 + 大字"的合规版海报，而不是退回纯白底图。

## 12. 主图 v4：从 ozon.ru 头部竞品学到的排版（2026-11-10）

样本：`raw/ozon-visual/montage-heroes.jpg`（真实抓取的 9 个头部商品主图）+ 用户提供的 8 张搜索页主图。逐条对照后，主图要这样做：

1. **标题占顶部 30–40%**：2–3 行、全大写、窄体粗黑（Oswald），字高 ≈ 画布宽 9–10%（1500 宽 → 140–150px），第一行品牌色、其余白色；行距 ≈ 1.0 字高。
2. **只讲一个核心数字**：尺寸/容量/长度做成一块超大数字徽章（约 100px），放在标题右下或右上，配一行小字说明（例：`68–91 СМ / телескопическая ручка`）。其余参数降级成底部小胶囊。
3. **产品占 50–60% 高度**：抠图 + 投影，压在标题下缘，可以稍微旋转，**必须比文字更抢眼**（先看产品，再看字）。
4. **2–3 个卖点条**：每条 ≤6 个词，左侧细线图标（毛刷/盾/尺/爪/水滴/LED），深色半透明圆角条 + 品牌色竖条。
5. **背景只做衬托**：纯色渐变或虚化场景 + 压暗蒙版；不放第二个主体，不与标题抢视线。
6. **文字覆盖 ≤25%**，不写价格、折扣、"хит продаж"；认证类徽章只写真有的（РУ № / MADE IN EU 不可编）。
7. **缩略图验收**：按搜索页卡片尺寸（约 300×400）缩小后，标题第一行和核心数字必须仍然可读；做不到就加大字号，不是加内容。
8. **版式顺序**：品牌条（左上小字）→ 标题 → 副标题一行 → 核心数字徽章 → 产品 → 卖点条 → 底部参数胶囊 → 页码（右下角 `DEMO BRAND · 01/08`）。

实现：`scripts/design-hero-v4-w2.py`（W2 原型，纯色渐变 + 抠图 + 字阶/徽章参数化）；对比图 `assets/design-system/w2-v4-vs-competitors.jpg`；成品 `assets/design-system/heroes-v4/W2.jpg`。
