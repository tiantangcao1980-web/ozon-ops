2026-11-06 的 `reports/ads-decide-2026-11-06.{md,json}` 与生成脚本在一次 git 历史清理中被误删（脚本未提交）。本引擎按归档产物的规则、阈值与输出结构**重建**，并用原始样本 `raw/ads-sample.csv` 做回归对齐。

## 入口

```bash
# 主 CLI

```

输出：`reports/ads-decide-<date>.md` + `.json`（`{date, thresholds, rows, budgetGroups, unknownColumns}`）。

## 输入

Performance 后台「搜索词报告」CSV，支持俄/英表头、`;` 或 `,` 分隔、金额 RU 格式（`1 234,56`）：

| 列（别名） | 含义 |
|---|---|
| Поисковый запрос / term | 搜索词 |
| SKU / Артикул | 商品 |
| Показы / impressions | 曝光 |
| Клики / clicks | 点击 |
| Расход / spend | 花费（RUB 或 CNY，由 `--spend-cur` 指定） |
| Заказы / orders | 订单 |
| Выручка / revenue | 广告销售额 |
| В корзину / cart | 加购 |
| Название товара | 商品标题（用于推导「词是否在标题里」） |

派生指标：CTR = clicks/impressions、加购率 = cart/clicks、CVR = orders/clicks、ACOS = spend/revenue（收入为 0 记 99 = >100%）、CPC = spend/clicks；`inTitle` 由「词是否为标题子串」推导，`longTail` = 词数 ≥3，`headTerm` = 词数 ≤2。

## 判定规则（顺序即优先级，primary = 首个命中）

| # | 条件 | 结论 | 动作 |
|---|---|---|---|
| 1 | 曝光 ≥3000 且 CTR <0.8% | 词或商品卡不匹配 | 暂停该词（或降到最低出价） |
| 2 | 曝光 ≥3000 且点击 ≥30 且加购率 <2% | 商品卡/价格无说服力 | 不暂停，先改主图/价格，2 周后再看 |
| 4 | 点击 ≥20 且 ACOS ≤25% | 词在赚钱 | 加价 10–20%，并加进标题/后台关键词 |
| 10 | 不在标题 且 点击 ≥30 且 ACOS ≤25% | 漏词（免费流量入口） | 把词加进标题/后台关键词 |
| 8 | 长尾 且 点击 ≥10 且 订单 ≥1 且 ACOS ≤25% | 长尾赚钱候选 | 连续 2 周 ≤25% 且自然单在涨 → 升级大词（需第 2 周数据） |
| 5 | 25% < ACOS ≤40% 且 点击 ≥20 | 边缘 | 维持出价，观察 7 天 |

规则 3/6/7/9 需要两周对照数据，本引擎只保留结构、不做判定。

## 预算分配（§8）

权重 `W = 广告销售额 / (1 + ACOS)`；按 W 占比分预算，再夹在 `[150, 40% × 总预算]`；剩余不硬分配，留储备。

样本结果：`P1 4000 / W2 4000 / H1 300`，剩余 1700 元。
